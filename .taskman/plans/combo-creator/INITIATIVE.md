# Цель

Построить **Figma-подобный веб-редактор регбийных комбинаций** (создание + анимация на поле, экспорт в GIF). Репозиторий greenfield (`docs/design.md` + `.gitignore`). План разбит на 3 этапа, каждый — отдельный pi-plan с детальными delegation-задачами и verification gates.

# Зафиксированные решения (из дизайн-дока + грилла)

1. **Модель данных = только keyframes.** Позиции объектов в ключевые моменты, между ними — линейная интерполяция. **Пас/удар = перемещение объекта «мяч»** между игроками через ключевые кадры (отдельных событийных сущностей нет, резолвер событий не нужен).
2. **Рендерер = Konva.js** (+ `react-konva`): drag&drop, масштабирование, линии, стрелки, hit-testing из коробки.
3. **Экспортёр = gif.js** (MP4 — **non-goal**, ffmpeg.wasm не нужен).
4. **Поле = регби hardcoded / config-модуль** (мульти-спорт — **non-goal**).
5. **Стек:** React + TypeScript + Vite, Konva.js, gif.js, zustand.
6. **База:** Biome (lint+format) + Vitest (unit) + GitHub Actions CI (lint, typecheck, test, build).
7. **Мяч входит в ядро MVP** (иначе пас/удар не выразить).

# Non-goals
- MP4-экспорт и ffmpeg.wasm.
- Мульти-спорт / configurable field.

# Разбивка планов и порядок

- **`combo-foundation`** (этап 1) — проектный скелет и туллинг: Vite+React+TS, Biome, Vitest, GitHub Actions, зависимости (konva/react-konva/zustand/gif.js), структура папок + базовые типы (`BaseObject`, типы объектов/проекта). *Фундамент без которого ничего не работает.*
- **`combo-core-mvp`** (этап 2, зависит от foundation) — рабочее MVP: поле (rugby config), объекты Player/Ball, zustand-store, модель ключевых кадров + линейный `Interpolator` (с unit-тестами), drag&drop + выделение, Timeline UI, playback, экспорт GIF (gif.js), сохранение/загрузка JSON (с версионированием схемы). *Здесь получается создавать и анимировать базовые комбинации и экспортировать GIF.*
- **`combo-deepening`** (этап 3, зависит от core-mvp) — наращивание: объекты Arrow/Circle/Text/Rectangle/Highlight, панель Properties, undo/redo (Ctrl+Z/Y), горячие клавиши, снаппинг/мультиселект/дублирование, импорт/экспорт YAML, панель Layers, опционально сглаживание интерполяции (Catmull-Rom/easing).

# Как части складываются
Foundation даёт собираемый, линтуемый, тестируемый проект с CI и каркасом. Core MVP строится поверх скелета и типов, реализуя замкнутый цикл «нарисуй → анимируй ключами → проиграй → экспортируй GIF / сохрани JSON». Deepening наращивает MVP до полного видения дизайн-дока, не трогая ядро модели данных (всё те же keyframes).

# Риски (адресуются внутри планов)
- **Линейная интерполяция → рывки** на резких сменах направления. Сглаживание (Catmull-Rom/easing) — опциональная задача в deepening.
- **Версионирование схемы сериализации** — учесть в задаче JSON save/load (поле `schemaVersion` + migration-хук).

# Валидация
- Unit-тесты (Vitest) для чистой логики: `Interpolator` (интерполяция, edge-кейсы границ/clamping), сериализация/десериализация (round-trip, version migration).
- Ручное QA-описание в задачах UI/экспорта (пошаговый сценарий + ожидаемый результат).
- CI прогоняет lint/typecheck/test/build на каждый push.
